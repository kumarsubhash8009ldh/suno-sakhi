# 🌸 Suno Sakhi (सुनो सखी)

> Real-time voice & video calling, companionship, and consultation platform connecting callers with hosts (Sakhis).

---

## 📱 Features

- **Real-Time Voice & Video Calling**: WebRTC-powered audio and video calls with dynamic call timers and volume controls.
- **Wallet & Monetization Engine**: Real-time per-minute call billing, wallet recharge requests, and virtual gift system.
- **Host (Sakhi) Management**: Dedicated host onboarding, KYC verification, earnings dashboard, and UPI/bank withdrawal workflows.
- **Admin Control Panel**: Review caller/host records, verify KYC documents, manage wallet recharge approvals, and set commission rates.
- **Capacitor Android Native App**: Packaged with Capacitor 8 for Android deployment.
- **Dual Data Mode**: Cloud Firestore synchronization with automatic local JSON fallback.

---

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Tailwind CSS, Vite, Lucide Icons, Canvas Confetti
- **Mobile**: Capacitor Android
- **Backend / Real-time**: Node.js microservice (`server.cjs`) & WebRTC signaling
- **Cloud Database**: Google Cloud Firestore / Firebase

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

### 4. Build Android APK
Run the automated build script:
```cmd
build_apk.bat
```
